# Smart Inventory V1 — Migración RETIRADA

> **NO USAR EN PRODUCCIÓN.**

La migración desde Smart Inventory V1 fue retirada por decisión de producto porque V1 nunca se utilizó como fuente operativa real.

El baseline productivo de Smart Inventory V2 será:

1. Base operativa inicial en cero.
2. Catálogo depurado proveniente de SAINT.
3. Configuración de unidad base, presentaciones/empaques, mínimos y máximos.
4. Existencia inicial de SAINT registrada una sola vez mediante movimientos trazables.
5. A partir de ese punto, todo stock se deriva exclusivamente de movimientos de Smart Inventory.

El código histórico de migración V1 puede permanecer en el repositorio como referencia técnica temporal, pero no forma parte del shell, navegación ni flujo productivo.
